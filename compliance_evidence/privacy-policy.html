Privacy Policy

Last Updated: October 25, 2026 | Application: YouTube Automation Agent
Important YouTube API Notice: YouTube Automation Agent uses YouTube API Services. By using this application or connecting your channel, you acknowledge and agree that your data is processed in accordance with the YouTube API Services Terms of Service and the Google Privacy Policy.

1. Information We Access and Collect

YouTube Automation Agent accesses and processes user data strictly necessary to fulfill its automated educational content publication functions. This includes:

  • OAuth 2.0 Credentials: Client ID, client secret, and refresh tokens authorized by the channel owner to upload video files and manage publication status via https://www.googleapis.com/auth/youtube.upload.
  • Video & Channel Metadata: Video titles, descriptions, tags, upload IDs, and publication timestamps generated by our autonomous pipeline.

We do not collect personal identifying information (PII), end-user passwords, financial details, or spectator viewing history.

2. How We Use and Store API Data

All YouTube API data is utilized solely for:

  • Uploading generated educational video files directly to the authorized channel.
  • Checking upload status and logging video IDs for quality evolution tracking.

Storage & Security: OAuth access and refresh tokens are stored exclusively in encrypted environment secrets within the owner's private GitHub repository infrastructure. No API data or user information is ever sold, leased, shared with third parties, or used for external advertising purposes.

3. Data Retention and Deletion Policy

We adhere to strict data minimization principles:

  • OAuth authorization tokens are retained only for as long as the owner maintains active automated scheduling.
  • Local temporary video rendering files and simulation metadata are purged immediately following successful publication.
  • Upon request or application decommission, all stored authorization tokens and metadata are permanently expunged within 24 hours.

4. User Access Revocation

Channel owners may revoke YouTube Automation Agent's access to their Google account and YouTube channel at any time through the official Google Security Settings page:

👉 https://security.google.com/settings/security/permissions

Revoking access immediately and permanently terminates the application's ability to interact with your YouTube channel.
