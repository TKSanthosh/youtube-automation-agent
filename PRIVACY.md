# Privacy Policy for AutoShorts / YouTube Automation Agent

**Last updated:** October 2026

## Overview
AutoShorts ("the Application") is an automated video creation and publishing tool designed to produce educational shorts and publish them to YouTube via the official YouTube Data API v3.

## Data Collection and Use
- **Google User Data**: The Application accesses your YouTube account solely to upload and manage educational videos created by your automation pipeline.
- **Authentication**: We use OAuth 2.0 to authenticate with Google APIs. Your authentication tokens (client ID, client secret, and refresh tokens) are stored locally or in your private GitHub repository secrets and are never transmitted to third parties.
- **Data Retention**: We do not store, harvest, sell, or share any personal identifiable information or Google user data.

## YouTube API Services
AutoShorts uses YouTube API Services. By using this application, you agree to be bound by the YouTube Terms of Service:
- [YouTube Terms of Service](https://www.youtube.com/t/terms)
- [Google Privacy Policy](https://policies.google.com/privacy)
